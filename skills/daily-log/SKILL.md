# Daily Log

Run `rf daily`, then curate Progress, Key Findings, Decisions, Problems/Uncertainty, and Next Actions. Include new Run/Observation/Hypothesis/Decision IDs and meaningful Git changes. Exclude command trivia, file browsing, and activity without research consequence. Never convert unverified agent inference or TEST/MOCK output into a finding.

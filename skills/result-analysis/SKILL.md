# Result Analysis

1. Resolve registered Run records, raw metrics, configs, commits, logs, and failure cases.
2. Compare against the declared baseline using primary, secondary, and guardrail metrics.
3. Report uncertainty, missing seeds, confounds, anomalies, and stop-condition outcomes.
4. Create an Observation describing what happened and its boundary.

A better metric does not prove the hypothesis or create an ACCEPT decision. Recommend a decision separately; formal Decision remains human/policy-owned.
